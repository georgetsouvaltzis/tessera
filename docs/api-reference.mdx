## What lives here

- `Inventory`: the exact public types and tiering decisions.
- `Guidelines`: naming, startup, theming, and public-boundary rules.
- `Capabilities`: terminal-specific behavior that affects portability.

## Before you dive in

- Start with [Overview](overview.md) if you are still learning the framework shape.
- Use [Install and Prerequisites](install-and-prerequisites.md) if you do not have a project running yet.
- Use [Your First App](first-app.md) if you want one complete runnable file before scanning raw type names.
- Use [App Model](app-model.md) if you need the lifecycle and message pipeline first.
- Use [Runtime and Screen Options](runtime-and-screen-options.md) if you are looking for startup configuration rather than raw type names.
- Use [Controls Overview](controls-overview.md) if you want the control families grouped by problem domain before opening the inventory.
- Use [Theme System](theme-system.md) if you are looking for styling and token guidance.
- Use [Architecture Overview](architecture-overview.md) if you are contributing to the repo rather than building an app.
