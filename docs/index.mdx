## Recommended path

1. Read [Overview](overview.md) for the product posture and public app model.
2. Follow [Getting Started](getting-started.md) to run the starter ladder in order.
3. Use [Starter Examples](examples.md) as the quick catalog for `HelloWorld`, `CounterForm`, and `WorkspaceApp`.
4. Open [Showcase](showcase.md) when you want the flagship and supporting demos.
5. Keep [API Reference](api-reference.mdx) nearby for exact surface names and capability details.

## Core concepts

- [Theme System](theme-system.md): semantic tokens, override hierarchy, and control-level hooks.
- [Custom Components](custom-components.md): widget authoring on the public path.
- [Design Contract](spec.md): the product rules that shape the public API.
