# Perf Baselines

This folder stores machine-readable baseline inputs and latest outputs for perf gates.

- `v1-slo-gate-baseline.json`: threshold baseline for startup/input-latency SLO gate.
- `latest-slo-gate-result.json`: latest gate run output (generated by script/tooling, optional in commits).
- `latest-runtime-e2e-result.json`: latest supplemental runtime-loop/decode/renderer-flush probe output (generated by script/tooling, optional in commits).
