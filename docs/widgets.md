# TeaSharp Widgets

This document is historical.

`TeaSharp.Widgets` is now internal widget infrastructure, not a supported public extension layer.

Use these public surfaces instead:

- `TeaSharp.Controls.Control` for custom widgets
- `TeaSharp.Controls.*` for reusable built-in controls
- `TeaSharp.Layout.*` for screen assembly

The old widget models and keymaps remain in the repo only as internal implementation bridges behind root controls.
