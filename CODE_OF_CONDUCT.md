# Code Of Conduct

Tessera is a public project. Treat the repo as a professional engineering space.

## Expected Behavior

- be respectful and direct
- assume good faith first
- discuss code and behavior, not people
- keep review feedback specific and actionable
- help keep the public onboarding path understandable

## Unacceptable Behavior

- harassment, threats, or discrimination
- personal attacks
- bad-faith derailment
- publishing private or sensitive information without consent
- hostile or abusive conduct in issues, PRs, reviews, or discussions

## Reporting

If you need to report conduct problems, contact the maintainers through GitHub private channels rather than filing a public issue.

Maintainers may edit, hide, lock, or remove content that makes the project unsafe or unproductive.
