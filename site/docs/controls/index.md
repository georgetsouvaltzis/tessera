Tessera has a broad built-in control surface. The public site groups controls by job instead of exposing one flat inventory first.

## Families

- Inputs
- Forms
- Navigation
- Data and tables
- Overlays
- Charts
- Workspace and ops

## Start here

For most apps, begin with:

- `Button`
- `TextInput`
- `Choice`
- `ListView<T>`
- `Table`
- `StatusBar`
- `Dialog`
- `CommandPalette`
